How combining works

Each received message normally needs one receive rule. An aligned block of IDs (for example 0x4F0 to 0x4FF) can be received through one rule instead; its lowest-ID message keeps the dispatch entry, and nw_can_dll.c must hand each ID to its own message (CoGeNT writes that code to CODE_GEN\MANUAL_ACTIONS.md). A block can only be combined when all its messages use the same layer and the same DLC.
